## Quantum Shield
This is a personal project developed in .NET, aimed at providing an extra layer of security for desktop applications. Quantum Shield is designed to lock and protect sensitive files and data, combining practicality with a touch of innovation.

![Quantum Shield](/images/projects/project-01/cover-01.jpg)

## Quantum Shield Key Features
- **Custom Locker Functionality**: Secure files and folders with ease.
- **Simple Yet Effective Security**: Built for personal use, ensuring a lightweight and efficient experience.
- **User-Friendly Interface**: Clean and easy-to-navigate design.
- **Unauthorized Access Warning**: Alerts to keep you aware of potential access attempts.
- **Custom Visuals**: Unique styling for a personalized touch.

## Aksharakadal
Built a Windows application called 'Aksharakadal' for reading and downloading eBooks using .NET and the OpenLibrary API.

![Aksharakadal](/images/projects/project-01/cover-02.jpg)

## Aksharakadal Key Features
- **Search Books**: Easily search for eBooks using keywords.
- **Download eBooks**: Download eBooks directly from the application.
- **Read Book Links**: Access links to read books online.
