For many, Adobe Photoshop and Illustrator are synonymous with creativity and visual excellence. But behind the layers, brushes, and vectors, there’s a powerful capability that often goes underused—scripting and coding!

## What Does "Coding" Mean in Design Tools?

Both Photoshop and Illustrator support scripting using JavaScript (ExtendScript), which allows designers to automate tasks, manipulate layers or paths, and even generate dynamic content. Think of it as a way to supercharge your workflow.

## Real-World Examples

**1.** **Batch Resizing and Exporting in Photoshop**  
Imagine you have 200 product images that need to be resized and saved in multiple formats. Instead of doing it manually, a simple script can automate the entire process:

```javascript
var files = Folder.selectDialog("Select a folder of images");
var output = new Folder("~/Desktop/Resized");

if (!output.exists) output.create();

var files = files.getFiles("*.jpg");
for (var i = 0; i < files.length; i++) {
    var doc = open(files[i]);
    doc.resizeImage(800, 800);
    var saveFile = new File(output + "/" + doc.name);
    doc.saveAs(saveFile, new JPEGSaveOptions(), true);
    doc.close(SaveOptions.DONOTSAVECHANGES);
}
```

**2.** **Auto-generating Business Cards in Illustrator**  
If you have a spreadsheet of names and titles, you can write a script to populate a business card template automatically. No need to manually enter each name—just let the code do the work.

**3.** **Dynamic Pattern Creation**  
You can write a script in Illustrator to generate patterns or layouts based on mathematical functions or data, useful in generative art or data-driven design projects.

## Benefits of Coding in Design

- **Speed:** Tasks that take hours can be done in minutes.
- **Consistency:** Automated processes reduce human error.
- **Scalability:** Easily handle hundreds or thousands of assets.
- **Customization:** Tailor tools and processes to your specific needs.

## Getting Started

Adobe provides documentation for scripting in both Photoshop and Illustrator, and tools like the ExtendScript Toolkit (or Visual Studio Code with the proper extension) help with writing and debugging scripts. Start with simple automations, and soon you'll be unlocking a new level of efficiency in your creative process!
